🏦 Bank Management System

A simple and interactive Bank Management System developed using HTML, CSS, and JavaScript. This project allows users to manage customer information with Add, Edit, Delete, Search, and Display functionalities.

📌 Project Overview

The Bank Management System is a frontend web application designed to manage customer details easily. It displays predefined customer records and allows users to add new customers, update existing information, delete records, and search for customers.

🚀 Features
Display Customers: View all customer details in a table.
Add Customer: Add new customer information.
Edit Customer: Select and edit existing customer details.
Update Customer: Save updated customer information.
Delete Customer: Remove customer records.
Search Customer: Search by customer name or account number.
Show All: Display all available customer records.
